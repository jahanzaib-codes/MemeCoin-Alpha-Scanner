# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security and integrity are paramount when scanning live smart contracts and handling on-chain transaction decoders:

1. **Responsible Disclosure**: Do not publish vulnerability disclosures, exploitable payloads, or security defects in public GitHub issues.
2. **Contact**: Open a confidential security advisory directly on GitHub or reach out to the development team via Telegram at `@JanzebBlockdev`.
3. **Response Timeline**: The maintainers strive to acknowledge and triage security reports within 24 hours and issue patch releases rapidly.
